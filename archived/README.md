# archived/

このディレクトリのファイルは、VIXフェーズ研究（本リポジトリのメイン分析）とは無関係です（監査指摘 A-9）。

- `tqqq_vs_spy_experiment.py`: TQQQ(3倍ナスダックETF)とSPYの3ヶ月パフォーマンス比較・相関ヒートマップ・対応のあるt検定を行う別の実験スクリプト。元は
  `import yfinance as yf (1).py` として、VIX研究のファイルと一緒にダウンロードフォルダに置かれていたが、
  内容的にはVIXフェーズ研究の結論には一切使われていない。

このスクリプト自体にも以下の問題があるため、修正せずアーカイブに留めている:
- `period="3mo"` の日次平均リターンを252倍して「年率リターン」としており、3ヶ月データから1年を外挿する妥当性が低い。
- シャープレシオが無リスク金利ゼロを暗黙に仮定している。
- `stats.ttest_rel` は両側検定なのに、結論の文言が「TQQQがSPYを上回っていることに有意差なし」と片側的な表現になっている。
- 3倍レバレッジETFと原資産を対応のあるt検定で比較しても、分散が大きく異なるため検出力がほぼない。
