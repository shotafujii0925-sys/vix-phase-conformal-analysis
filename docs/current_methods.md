# 修正後の手法と結果の読み方

最新数値は[README](../README.md)と[自動生成の全数値表](key_results.md)を参照してください。

前半はVIX水準のカテゴリと126市場営業日先の価格リターンを比較します。
日次ANOVA、Welch、Kruskal-Wallis、Holm補正は観測間独立性を満たさず、参考検定です。
HAC回帰はVIXの63日Zスコアを使う別モデルで、水準カテゴリの有意性を直接再検定したものではありません。
説明力やeta²は全標本内の量であり、売買成績やアウトオブサンプル予測力を表しません。

Panicエピソードは63営業日の空白で候補を作り、126日先リターンの期間を共有する候補を統合します。
2020年の2候補は1つになり、8エピソードの7個でNormal平均を上回ります。
Normal平均は同じ全標本から推定した比較基準です。非重複にしても独立性や成功確率0.5は保証されません。
二項p=0.0703はその仮定に条件付けた参考計算で、確証的な有意性とは扱いません。
LOCOでは除外したエピソードの開始日〜最終Panic日を除きます。
将来リターンが危機にかかる他の起点までは除かないため、完全に危機の影響を排除した標本ではありません。

後半はVIXの1/21市場営業日先水準を予測します。特徴量作成前の営業日インデックスからtarget_dateを保持します。
欠損除去後のh行をh営業日として扱いません。再学習はその日にtargetが確定済みの行のみを使用します。
予測は終値観測後に発行し、その日に確定した過去の残差を先に解放します。
較正期間末尾の未確定残差もキューで保持して、対象日到来時に追加します。
その較正残差は区間を発行していないので、ACIのalpha更新には使いません。

較正分位点はceil((n+1)(1-alpha))番目の順序統計量です。FixedSplit/naiveでは順位超過時に無限区間とします。
実データの固定alpha=0.1ではこの状況は起きません。ローリングの実務的変種は最大残差で打ち切ります。
alphaの制限、時系列依存、ローリング窓とモデル再学習を含むため、分布によらない被覆保証は主張しません。
下限0クリップ自体は非負ターゲットの被覆を減らしません。

32手法比較を1群にして、個別95%CIとBonferroni補正CIをJSONに保存します。
判定に使うのは補正CIです。ブートストラップ10,000回とブロック長21/42件は固定値で、尾部の推定にも誤差があります。
非定常性に対して厳密な同時被覆を保証したものではありません。

検出力について、同じ観測標本の効果量を真の効果と仮定する事後検出力は削除しました。
80%検出力の最小検出効果量MDEを、独立・等分散ANOVAの計画上の近似として表示します。
観測標本は群が大幅に不均衡で重複もあるため、実際の見逃し確率として解釈できません。
