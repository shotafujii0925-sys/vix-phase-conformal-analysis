## 1. データと時系列設計

### 1.1 データソースと再現性

既定のデータソースは同梱スナップショット `data/vix_sp500_tnx_raw.csv`（2026-09-08取得、8,565行）である。`build_dataset()` はこのCSVから **生データ3列（SP500 / VIX / Treasury_10Y）のみ** を読み、派生列（将来リターン、フェーズ分類、Zスコア、金利差分）は毎回再計算する。派生列をCSVから読まないのは、パイプラインのロジック自体を毎回実行して検証するためである。

`build_dataset(source="online")` を明示した場合のみ yfinance から再取得する。どちらを使ったかは実行時に必ず標準出力へ表示される。

### 1.2 欠損・重複・休日の扱い

| 項目 | 扱い |
|---|---|
| 日付インデックス | 昇順であることを検証（`validate_raw`）。重複日付は検出して例外を送出 |
| SP500 / VIX | 両方が揃う営業日のみ使用（`dropna(subset=["SP500","VIX"])`） |
| Treasury_10Y | 31日欠損（債券市場のみ休場の日）。金利を使う分析だけ標本が小さくなる（N=8,439 → 8,347） |
| 値域検証 | VIXが5〜100、SP500が正、金利が0〜20%（%表記）であることをassertで検証 |

### 1.3 将来リターンの定義（限界の明示）

`Return_6M` は `SP500.shift(-126) / SP500 - 1` であり、**126営業日先**である。暦日で正確に6ヶ月後ではない。取引所休場日の分布により、実際の経過日数は期間によって数日ずれる。この点は結論に大きく影響しないと考えられるが、検証はしていない。

### 1.4 先読みバイアスの排除（修正履歴あり）

- 特徴量は全て `shift(+k)` と `rolling()`（過去方向のみ）。負のshiftは目的変数の生成にのみ使用する。
- **ウォークフォワード学習窓の修正**: 当初は再学習時点 `start` に対して `feat.iloc[:start]` を学習に使っていたが、行 i の target は i+h 時点で実現するため、末尾h行のtargetは再学習時点で未実現だった。現在は `feat.iloc[:start - h + 1]` に修正済み（h=1で1行、h=21で21行の混入を解消）。
- **ACI初期履歴の修正**: 較正期間の残差のうち末尾h件はtargetが評価期間側で実現するため、初期履歴から除外している。
- これらは `tests/test_repo.py::test_walk_forward_training_targets_are_realized` と `test_features_contain_no_future_information` で検証している。

### 1.5 期間分割

| 期間 | 範囲（h=1） | N | 用途 |
|---|---|---:|---|
| Train | 1990-04-02 〜 2000-05-30 | 2,520 | モデルの初回学習（以後walk-forwardで拡張） |
| Calibration | 2000-05-31 〜 2002-05-30 | 500 | 固定分位点の算出・ローリング履歴の初期化 |
| Test | 2002-05-31 〜 2023-12-28 | 5,421 | **全ての評価はこの期間のみ** |

3期間は重複なし・時系列順。モデルごとに欠損開始位置がずれてもTest期間が一致するよう、位置インデックスではなく**日付境界**でスライスしている。

## 2. VIXフェーズと将来リターン

### 2.1 検定の選択理由

VIXを4段階（Normal<20 / Alert 20-30 / Fear 30-40 / Panic>40）に分類し、6ヶ月先リターンを比較した。閾値20/30/40は市場で慣行的に用いられる区切りを採用している。

- **標準ANOVA**: 基本の比較
- **Welch ANOVA**: 等分散性が棄却されたため（Levene/Bartlettいずれもp<1e-190）
- **Kruskal-Wallis**: 分布の非正規性に対する頑健性確認
- **Welch型ペアワイズ + Holm補正**: 等分散を仮定しないペアワイズ比較、多重比較補正あり

3つの検定すべてで同じ方向の結論が得られた（詳細は key_results.md）。

### 2.2 重複リターン問題

6ヶ月リターンを日次でスライドさせているため、隣接する観測値は計算期間の125/126を共有する。ANOVA型モデル（`Return_6M ~ C(VIX_Phase)`）残差のDurbin-Watson統計量は **0.0323**（独立なら2.0付近）で、極めて強い正の自己相関がある。

対処として2つの経路で検証した。

1. **間引きサンプリング**: 21/63/126営業日ごとに標本を間引く。Daily→Monthlyでは有意差が残るが、Quarterly以降では検定間で結論が割れ、Semiannualでは全て非有意になる。
2. **検出力分析**: ただし間引きは標本サイズも削るため、「非有意」が「効果なし」を意味しない。Semiannual(N=67)の検出力は0.283であり、真の効果があっても7割の確率で見逃す。

**この2つを併せて読むと、「間引くと有意差が消える」は「自己相関の除去」と「検出力の喪失」の両方を含む**。どちらの寄与が大きいかを本研究は分離できていない。

### 2.3 HAC補正とラグ幅感度

VIX_Zと米10年債利回りを説明変数とする回帰にNewey-West型HAC標準誤差を適用した。ラグ幅は分析者が選ぶパラメータであり結論を左右しうるため、21〜315営業日の6通りで振った。**6通りすべてでVIX_Zは5%水準で非有意**（p=0.069〜0.114）。ただしmaxlags=21のp=0.0688は10%水準では有意であり、境界的である。

### 2.4 金利変数の定常性

米10年債利回りを水準のまま使うと見せかけの回帰のリスクがある。ADF検定は単位根を棄却できず、KPSS検定は定常性を棄却した（＝非定常の可能性が高い）。1日差分に置き換えると両検定とも定常を支持する。

差分に置き換えるとVIX_Zの非有意という結論は変わらないが、水準では完全に非有意だった金利項が p=0.0499 まで動く。**これは0.05をわずかに下回る境界値であり、数十件の未補正検定の中の1つであるため、有意とは判断しない**（探索的結果として位置づける）。

### 2.5 Leave-one-crisis-out とエピソード単位推論

Panic群(n=203日)が実質何個の独立イベントかを、63営業日以上の間隔で区切るクラスタリングで確認したところ、**9個の独立エピソード**（1998, 2001, 2002, 2008, 2010, 2011, 2015, 2020×2）が検出された。124日（61%）が2008年GFCに集中しているのは事実だが、それ以外にも6つのエピソードがある。

2008年と2020年の両方を除外しても（残りn=44日）、Panic群とNormal群の平均差は符号・大きさともに維持された。

**ただしここで重要な注意がある。** LOCOで併記されるWelch-t検定のp値は、本レポート2.2節で「過大評価される」と論じた日次重複標本そのものに対して計算されている。**したがってこのp値を有意性の根拠として用いることはできない**（本研究の初期版はこれを根拠として扱っており、それは内部矛盾だった）。

代わりに、**1エピソード = 1観測**として集計するブロック単位の推論を併記している。

- 9エピソード中 **8個** でNormal群の平均を上回った
- 符号検定（両側二項検定）: **p = 0.0391**
- エピソード平均リターンの中央値 +0.1502、範囲 [+0.0193, +0.3326]

この検定はエピソード内部の重複を完全に回避する代わりに、情報の大半を捨てている。**n=9の検出力は低く、p=0.039も0.05の近傍である**。日次検定（過大評価）と符号検定（保守的）の間に真の不確実性があり、本研究はどちらか一方を「正しい有意性」として採用しない。

### 2.6 経済的有意性

- VIX_Z単体モデルの調整済みR² = **0.0055**（説明力0.55%）
- ANOVAのeta² = 0.0610（フェーズが説明する分散の6.1%）
- Panic群でも6ヶ月先リターンの最小値は **-27.9%**
- 34年間でPanic水準は9エピソードのみ（シグナル頻度が極めて低い）
- ^GSPCは価格指数であり、配当を含まない（トータルリターンとの差は本研究では定量化していない）

## 3. 時系列コンフォーマル予測

### 3.1 問題設定の変更理由

前半で、VIX水準による将来リターンの説明力が1%未満であり、日次重複による見かけの有意性も確認された。方向を当てる点予測の追求ではなく、**市場状態の不確実性を区間として評価する**問題へ視点を移した。目的変数はVIX自体のh営業日先の水準である。

### 3.2 比較する4手法

点予測モデル・学習期間・評価期間・予測ホライズン・使用可能な情報・下限クリップ・評価指標・危機局面の定義を**全て統一**した上で、以下を比較する。

| 手法 | 残差窓 | alpha | 意味 |
|---|---|---|---|
| A. ACI | ローリング500日 | 適応（オンライン更新） | Gibbs & Candes (2021) の考え方 |
| B. RollingFixed | ローリング500日 | 固定0.10 | **Aとの差 = alphaを適応させる効果** |
| C. FixedSplit | 較正期間で固定 | 固定0.10 | **Bとの差 = 残差窓を更新する効果** |
| D. NaiveBaseline | 較正期間で固定 | 固定0.10 | モデルを使わない無条件区間 |

**初期版の反省**: 当初はA（ローリング窓＋適応α）とC（固定）しか比較しておらず、差の何割が「αの適応」で何割が「窓の新しさ」かを分離できていなかった。Bを追加したことで分離が可能になった。

**Cの位置づけ**: Cは較正期間（2000-2002年）の分位点を21年間更新しない設定である。これは実務的な非適応手法の代表ではなく、**極端なケース**として理解すべきである。AがCに優れて見える分には、この設定の極端さが寄与している。

### 3.3 ACIの実装（原論文との差分を明示）

```
各時点 i で:
  1. 判明済み残差のローリング窓から (1 - alpha_t) 分位点 q を計算
  2. 区間 [max(pred_i - q, 0), pred_i + q] を発行  ← VIXは非負なので下限をクリップ
  3. 発行済み区間をキューに積む
  4. h ステップ経過して実現値が判明したら、キューから取り出し
     「そのとき実際に発行した（クリップ後の）区間が実現値を含んだか」で被覆判定
  5. err に基づき alpha_{t+1} = clip(alpha_t + gamma * (alpha_target - err))
```

**修正履歴**: 初期版は「h日前の残差」を「現在時刻のq」と比較して被覆判定していた。これは (a) 判定に使うqが発行時点のものと異なり、(b) 下限クリップ後の実際の区間ではなく残差の大小で判定するという2点で誤りだった。現在は発行時点の区間そのものをキューに保存して判定している。

**原論文との差分（限定的な主張）**:
- alphaの更新則は Gibbs & Candes (2021) と同じ形式である。
- 一方、本実装は**全履歴ではなく直近500件のローリング窓**から分位点を取る。これは実務的な変種であり、原論文の理論的保証がそのまま成り立つとは限らない。
- 下限を0でクリップしているため、区間は厳密な対称コンフォーマル区間ではない。
- したがって本研究は「**ACIの考え方に基づく実装**」であり、「原論文を厳密に再現した」とは主張しない。

**フィードバック遅延**: h営業日先を予測する場合、時刻tの予測の当否はt+h時点まで判明しない。この遅延をキューで明示的に処理している（`test_aci_feedback_is_delayed_by_h` で検証）。

### 3.4 手法差の不確実性（ブロックブートストラップ）

Winkler scoreやカバレッジの数%の差を点推定の順位だけで判断しないため、moving block bootstrap で95%信頼区間を推定した。

- **ブロック長**: `max(21, 2h)`。h=1で21営業日（約1ヶ月、残差の短期自己相関を保持）、h=21で42営業日（目的変数の重複期間21日の2倍）。**h営業日先予測では目的変数が重複するため、ブロック長がh未満だと重複構造を壊す**。
- **反復回数**: B=1,000
- **判定**: 差の95%信頼区間が0をまたぐ場合、「点推定では差があるが、明確な差は確認できない」と記述する。

### 3.5 主要な結果の読み方

詳細な数値は [key_results.md](key_results.md) を参照。解釈上の要点は以下の通り。

**(a) alphaの適応には効果がある（h=1）**

A vs B（窓は同じ、alphaだけ違う）のWinkler差は、LinearでもGBMでも95%信頼区間が0を含まない。**alphaを適応させること自体に効果がある**と言える。

**(b) 窓の更新だけでは、効率は明確に改善しない（h=1）**

B vs C（alphaは同じ、窓の更新だけ違う）のWinkler差は、LinearでもGBMでも95%信頼区間が0をまたぐ。ただし**カバレッジは有意に改善する**（+2.1〜2.8pt）。つまり窓の更新はカバレッジを目標に近づけるが、区間幅とのバランスまで改善するとは言えない。

**(c) 点予測が弱いと、適応型でも素朴な区間に負ける（h=1、GBM）**

A vs D（ACI vs モデルなし）のWinkler差はGBMでは **+0.668、95%CI [+0.116, +1.352]** であり、**ACIの方が有意に悪い**。一方Linearでは −0.982、95%CI [−1.686, −0.466] でACIが有意に良い。**コンフォーマル予測の枠組みは、点予測の質が悪いことを補ってはくれない。**

**(d) h=21ではほぼ全ての差が区別できない**

h=21では、Linear・GBMのほぼ全てのペアで95%信頼区間が0をまたぐ。**初期版は「h=21ではACIの優位性が消え、Linear+Fixedが全体最良」と断定していたが、これは点推定の順位を過剰に読んだものであり、正しくは「この標本設計では手法差を統計的に区別できない」**。唯一の例外はGBMのA vs Dで、ACIが有意に劣る（+4.724、95%CI [+2.176, +7.318]）。

**(e) 局面別に見ると、Panicでの差は劇的**

VIXフェーズ別のカバレッジ（h=1、GBM）は、Normalではどの手法も88〜96%だが、**Panicでは ACI 83.2%(153/184) に対し RollingFixed 48.9%、FixedSplit 19.6%、Naive 38.0%** と大きく開く。ここでの差はalphaの適応によるものが支配的である（Bも大きく崩れているため）。ただしACIでも目標90%には届かない。

### 3.6 危機局面の検証

**エピソード数と標本サイズの限界を先に明示する。** Test期間内のPanicエピソードは7個であり、各エピソードの前後窓はN=21である。**個別エピソードのカバレッジ（例: 7/21 = 33.3%）の標準誤差は約10ptあり、エピソード間の差の多くはノイズの可能性がある**。以下は7エピソード全体の傾向として読むべきである。

- 突入前(pre)の時点で、既にどの手法も目標90%を下回っている（74〜81%）。Panic突入前の数週間に既にVIXの上昇が始まっているためと考えられる。
- 突入後(post)はACIの劣化が最も小さい（63.3%）が、それでも目標には遠い。
- FixedSplitは38.8%まで崩れる。

**危機発生日の定義の限界**: 本研究はPanic（VIX>40）の初日を危機発生日と定義している。しかし市場ストレスはVIXが40を超える前から始まっており（preの時点で既にカバレッジが低いことがそれを示唆する）、この定義は「危機の開始」を実態より遅く捉えている可能性がある。

**h=21のpre/post逆転について（検証済み）**: 予測日基準で集計すると、h=21ではpreがpostより低いという逆転が生じる。これは「予測日基準のpre窓」の予測対象日(t+21)が既に危機突入後にかかっているためと考えられた。**そこで対象日(target date)基準で揃えて再集計したところ、逆転は解消した**（h=21のACI: pre 85.8% → post 43.2%）。**当初は仮説として記述していたが、既存データで検証可能だったため実際に検証し、仮説が支持されることを確認した。**

## 4. 点予測モデルについて

### 4.1 採用理由と設定

| モデル | 役割 |
|---|---|
| Persistence（ランダムウォーク） | 学習不要の最も単純なベースライン。VIXの強い持続性を考えると強力な比較対象 |
| Linear（線形回帰） | 同じ特徴量での線形ベースライン |
| GBM（HistGradientBoostingRegressor） | 非線形性を捉えられるかを検証するための比較対象 |

**GBMのハイパーパラメータ（`max_depth=4, max_iter=200, random_state=42`）は計算時間を抑えるために事前に固定した値であり、探索は一切行っていない。評価期間も一切参照していない。** チューニングすれば結果が変わる可能性は排除できない。

### 4.2 特徴量

VIXのラグ（1/5/10/21/63日）、ローリング平均・標準偏差（21/63日）、S&P500日次リターン、実現ボラティリティ（21日）、10年債利回り（水準・1日差分）の14個。ラグの区切りは「前日・1週・2週・1ヶ月・四半期」に対応する慣行的なもので、**特徴量選択の最適化は行っていない**。全て予測時点で利用可能である（テストで検証済み）。

### 4.3 結果の解釈（限定を含む）

GBMは点予測MAEでも区間効率(Winkler)でも、h=1・h=21の両方でPersistence・Linearに劣った。

**ただしこれを「複雑なモデルは常に劣る」と一般化してはならない。** 次の限定が必要である。

- h=1のVIX水準予測は、persistenceのMAEが1.079という水準であり、そもそも改善余地が小さい課題である。
- ハイパーパラメータを調整していない。
- 目的変数がVIXの**水準**であり、変化率(ΔVIX)や実現ボラティリティであれば結果は異なりうる。**ただし目的変数の変更は新しい研究テーマになるため、本研究では実施せず今後の課題とする。**

言えるのは「**このデータ・この目的変数・この設定では、単純なベースラインが強かった**」という限定的な事実である。

## 5. 今後の課題

- 非重複リターンを前提としたサンプル設計での再検証
- 配当込みトータルリターン（^SP500TR等）での再計算
- 閾値・窓幅・γ・較正窓の感度分析（事前登録的に候補を固定した上で）
- 目的変数をΔVIXや実現ボラティリティへ変更した場合の比較
- サブ期間分割（1990-2007 / 2008-2023）での構造変化の検証
- GARCH-Xなど外生変数付きボラティリティモデルとの比較
- 米国以外の市場での再検証
